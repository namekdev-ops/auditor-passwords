\# Auditor de contraseñas



Script en Python que evalúa la fortaleza de una contraseña y da recomendaciones.



\## Cómo ejecutar



py main.py



\## Ejemplo de salida



Tu password tiene 20 caracteres

{'minusculas': True, 'mayusculas': True, 'numeros': True, 'simbolos': True}

Puntaje: 100 de 100

Nivel: Contrasena es muy fuerte

\- ¡Excelente! No hay mejoras obvias.



\## Qué aprendí



Aprendí la sintaxis básica de Python: funciones, condicionales, diccionarios, recorrido de cadenas y validación de caracteres.
