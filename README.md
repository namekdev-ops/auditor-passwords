\# Auditor de contraseñas 

&#x09;Script en Python que evalúa la fortaleza de una contraseña y da recomendaciones. 

\## Cómo ejecutar 

&#x09;py main.py 

\## Ejemplo de salida 

&#x09;Tu password tiene 20 caracteres

&#x09;{'minusculas': True, 'mayusculas': True, 'numeros': True, 'simbolos': True}
